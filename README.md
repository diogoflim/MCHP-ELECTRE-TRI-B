# MCHP-ELECTRE-TRI-B

A Python implementation of **ELECTRE TRI-B** combined with the **Multiple Criteria Hierarchy Process (MCHP)**, which sorts alternatives into ordered categories while respecting a hierarchy of criteria. An assignment is obtained not only at the root (overall) level but at **every intermediate node** of the criteria tree.


## Reference

The method implemented here is the one proposed in:

> Corrente, S., Greco, S., & Słowiński, R. (2016). Multiple criteria hierarchy process for ELECTRE Tri methods. *European Journal of Operational Research*, 252(1), 191–203.
